# Cozinha Fácil

PWA de receitas desenvolvido como material-base para uma atividade prática sobre acessibilidade em aplicações web/mobile.

O projeto apresenta uma interface simples de receitas que será utilizada em uma atividade prática de análise e aprimoramento da acessibilidade de aplicações web e mobile.

## Tecnologias

- HTML
- CSS
- JavaScript
- Web App Manifest
- Service Worker

## Execução

O projeto pode ser publicado diretamente pelo GitHub Pages e acessado por dispositivos móveis.

Após a publicação, o aplicativo pode ser instalado no dispositivo como um PWA.

> **Observação:** este projeto foi criado como material didático para uma atividade de acessibilidade.
